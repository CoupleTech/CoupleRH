# coupleRH - Departamento Pessoal e Gestão de RH

O motor definitivo para Departamento Pessoal e Gestão de RH brasileiro, desenvolvido com rigor legal (CLT/eSocial), foco em segurança de dados e uma experiência Premium.

## Stack Técnica (MVP)
- **Frontend**: React 19 + TypeScript + Vite + Tailwind CSS V4
- **Backend / BaaS**: Supabase (PostgreSQL, Auth, RLS)
- **Deployment**: Vercel

## Instalação e Execução

### Requisitos
- Node.js (v20+)
- NPM/Yarn/PNPM

### Como rodar o projeto localmente
```bash
# Clone o repositório e instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```
