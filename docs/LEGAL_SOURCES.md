# Fontes Legais

O software é orientado pelas seguintes fontes, que devem ser confirmadas na data de cálculo.
As leis e portarias abaixo são parâmetros de negócios:

- **CLT compilada**: [Decreto-Lei 5452/1943](https://www.planalto.gov.br/ccivil_03/decreto-lei/del5452compilado.htm)
- **Reforma trabalhista**: [Lei nº 13.467/2017](https://www.planalto.gov.br/ccivil_03/_ato2015-2018/2017/lei/l13467.htm)
- **FGTS**: [Lei nº 8.036/1990](https://www.planalto.gov.br/ccivil_03/leis/l8036consol.htm)
- **13º Salário**: [Lei nº 4.090/1962](https://www.planalto.gov.br/ccivil_03/leis/l4090.htm)
- **Documentação eSocial**: [Portal eSocial](https://www.gov.br/esocial/pt-br/documentacao-tecnica)
- **Portaria Ponto Eletrônico**: [MTP nº 671/2021](https://www.gov.br/trabalho-e-emprego/pt-br/assuntos/legislacao/portarias-1/portarias-vigentes-3/)
